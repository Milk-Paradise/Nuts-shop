# Локальный Nuts Store

GitHub: https://github.com/Milk-Paradise/Nuts-shop

Опубликованный сайт: https://nutsstore.termitsdigital.ru

Серверная админка: https://nutsstore.termitsdigital.ru/app

Настройка сервера описана в `DEPLOYMENT.md`. Общая папка проекта теперь
является единым Git-репозиторием для фронтенда и бэкенда.

Проекты находятся в `фронтенд` (Next.js) и `бекенд` (Medusa).

## Что установить

Node.js 24 LTS и Git уже установлены на этом компьютере. Другие программы для текущего запуска не нужны: переносные PostgreSQL, Redis и Meilisearch находятся в `.local`. Docker не требуется.

## Как запустить

Откройте PowerShell в этой папке и выполните:

```powershell
powershell -ExecutionPolicy Bypass -File .\start-local.ps1
```

Или через npm из этой же корневой папки:

```powershell
npm run dev
```

Команда запускает все сервисы в фоне. После завершения команды они продолжают работать.

Первый запуск после перезагрузки может занять около минуты.

- Магазин: http://localhost:3000
- Админка: http://localhost:9000/app
- Проверка API: http://localhost:9000/health

Логин и пароль **локального** администратора записаны в `.local/admin-credentials.json`. Это отдельная учётная запись, пароль GitLab здесь не используется.

## Связь каталога

Фронтенд читает `/store/products` Medusa на сервере, с publishable API key. Настройки находятся в `фронтенд/.env.local`; `USE_MOCK=false` отключает демонстрационный каталог.

При добавлении товара в админке укажите:

1. Статус «Опубликован», канал продаж и цену варианта в RUB.
2. Категорию с handle `smartphones`, `headphones`, `tablets`, `laptops`, `watches` или `accessories`.
3. В Metadata товара: `brand` = `Apple`. Витрина изначально настроена только на Apple.
4. Остаток варианта на складе Main Warehouse; цвет и память задаются опциями «Цвет» и «Память».

После сохранения обновите страницу магазина. Название, цена, фото и остатки берутся из API без подмены моками. Оформление заказа в этом фронтенде по-прежнему отправляет заявку в Telegram и требует настройки бота; оплата и заказы Medusa в задачу подключения каталога не входят.

## Изменения

- Добавлен адаптер формата Medusa, серверный publishable key и чтение страниц каталога.
- Для локальных изображений Medusa используется встроенное файловое хранилище; S3 для других окружений сохранён.
- Для локального запуска используется `--no-lint`: в исходном бэкенде описан отдельный блокирующий lint-барьер. Это не результат успешной полной сборки бэкенда.
- Удалённые репозитории не изменялись, изменения находятся только локально.
