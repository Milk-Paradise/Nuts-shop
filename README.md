# Nuts Store — техника Apple

Локальный проект Next.js 16 (App Router), React 19, TypeScript strict, Tailwind CSS 4,
Zustand 5 и FSD. Нужен Node.js 22.12+.

## Запуск

```powershell
npm install
Copy-Item .env.example .env.local # только при первой настройке, не перезаписывайте секреты
npm run dev
```

Откройте http://localhost:3000. Для production: `npm run build`, затем `npm start`.

## Что работает

- Главная с категориями, подборками, фотографиями и анимациями React Bits.
- Серверный каталог: поиск, категории, бренды, цена, наличие, сортировка, пагинация.
- Карточка товара: цвет и конфигурация, изменение цены, связанные товары.
- Корзина с количеством/удалением/суммой и сохранением в localStorage.
- Избранное и таблица сравнения с сохранением между посещениями.
- Оформление: контактные поля, доставка/самовывоз, валидация, статусы отправки.
- Telegram HTML: позиции, варианты, количество, серверные цены, сумма, контакты,
  адрес, комментарий и московское время. Без токена возвращается 503, без ложного успеха.
- Автотема по местному времени: dawn 06–09, day 09–18, dusk 18–21, night 21–06.
  Кнопка в шапке циклически переключает авто → светлая → тёмная → авто.
- Мобильное меню, native dialog с управлением фокусом, reduced-motion.

## Telegram

Создайте бота через @BotFather (`/newbot`), добавьте его в группу с правом отправки.
Отправьте в группу `/start@username_бота`; `getUpdates` Bot API покажет `message.chat.id`.
Сохраните в `.env.local` (не в исходном коде и не в `NEXT_PUBLIC_*`):

```dotenv
TELEGRAM_BOT_TOKEN=токен
TELEGRAM_CHAT_ID=-1001234567890
```

Перезапустите сервер. В production задайте те же секреты в панели хостинга.
Webhook не нужен для отправки. Пока USE_MOCK=true, Telegram-сообщения помечены «ДЕМО».
Настоящая отправка без предоставленных настроек не проверялась.

## Каталог и бэкенд

Адрес `https://gitlab.termitsdigital.ru/termits/catalog-backend/api` при проверке
вернул HTML страницы входа GitLab, а не JSON каталога. Это адрес репозитория,
не подтверждённый URL работающего API. Учётные данные GitLab не записывались в проект.

По умолчанию `USE_MOCK=true`. 10 демонстрационных товаров находятся в
`src/entities/product/api/mock.ts`. Цены, рейтинг и наличие —
демонстрационные данные, не синхронизированы с магазином.

Для интеграции работающего сервера:

1. Уточните базовый URL развёрнутого API, путь получения товаров и DTO.
2. Адаптируйте `src/entities/product/api/catalog.ts` (явный TODO, Zod-схема).
3. Задайте CATALOG_API_URL, CATALOG_PRODUCTS_PATH и при необходимости CATALOG_API_TOKEN.
4. Для внешних фото задайте CATALOG_IMAGE_HOST, перезапустите сервер.
5. Переключите `USE_MOCK=false`. Ошибки API не маскируются под успешный мок-ответ.

Текущий адаптер ожидает массив Product[]; пример структуры — типы в
`src/entities/product/model/types.ts`. Category живёт в независимом слайсе.
Фотографии моделей могут отличаться от выбранного цвета — UI сообщает об этом.

## Архитектура

```text
src/app        провайдеры, стили, маршрутные композиции и Route Handler
src/pages      композиция страниц
src/widgets    шапка, footer, hero, сетка, корзина, выбор варианта, сохранённые товары
src/features   действия пользователя и темы
src/entities   product / category / cart / favorite / order
src/shared     UI, анимации, форматирование, конфигурация и Telegram transport
```

Root `app/` — тонкие Next.js entrypoints с реэкспортом в `src/app`.
Root `pages/README.md` не даёт Next.js воспринимать FSD `src/pages` как Pages Router.
Next требует framework app/pages на одном уровне, поэтому эти мосты необходимы.

Store создаются фабриками внутри entity providers через useState и монтируются в
`src/app/providers`. Контексты и hooks остаются в entities, чтобы features/widgets
не импортировали слой app. RSC не читают Zustand. Серверный и первый клиентский
снимки пустые и одинаковые; localStorage читается только после mount.

Public API каждого слайса — index.ts. Для server-only каталога выделен публичный
`entities/product/server.ts`, не попадающий в клиентский barrel. Слайсы entities
не импортируют друг друга; order использует минимальный структурный интерфейс каталога.

## Проверка

```powershell
npm run typecheck
npm test
npm run check:fsd
npm run build
```

Тесты проверяют изоляцию stores, количества, серверную цену/остаток, фильтры,
границы тем, HTML-экранирование, ошибки API и повторные запросы без реальной отправки.

## Ограничения перед публичным запуском

- Уточнить реальный API каталога и реальные коммерческие данные.
- Добавить реквизиты оператора и согласованные условия обработки данных/гарантии.
- Защита повторов и лимит заявок сейчас process-local (30 минут и 5 запросов за 10
  минут). Для нескольких серверов нужны Redis/SQL и лимитирование на reverse proxy.
  Указатель x-forwarded-for должен перезаписываться доверенным reverse proxy.
- Telegram — канал уведомления, не база заказов. Для надёжного хранения при сбоях
  требуется БД заказов и outbox. Неоднозначный timeout не повторяется автоматически.
- Неподтверждённая отправка сохраняется в localStorage без контактных данных.
  После перезагрузки повтор заблокирован до явного подтверждения менеджером,
  что заявки нет. Корзина блокируется на время HTTP-запроса.
- Сейчас нет оплаты, личного кабинета, SMS или настоящей системы отзывов.

React Bits: `src/shared/ui/react-bits/LICENSE.md`. Изображения Apple и исходного
магазина используются как демонстрационные; перед публикацией подтвердите право использования.

## Оформление Nuts Store

Витрина показывает только Apple, включая данные реального API. Прежние цены не отображаются.
Контакты магазина — только email. Текущий адрес сохранён: info@11centov.ru; заменяется через STORE_EMAIL в src/shared/config/index.ts.
Телефон покупателя в форме заказа сохранён для согласования получения.

## Анимированный футер

Общий футер на всех страницах объединяет сцену по Tech-Noir референсу
MotionSites, контакты и навигацию. Отдельного блока на главной больше нет. Сцена с MacBook хранится локально в public/media (WebM ~175 КБ),
загружается при приближении к экрану и служит фоном всего футера: контакты и ссылки
расположены поверх затемнённой сцены. Промотекст, CTA и кнопка паузы убраны.
При reduced motion показывается постер. Вне экрана и в скрытой вкладке видео останавливается.
Исходный Cloudinary аккаунт отключён, поэтому использована доступная анимация из
публичного превью референса; подробности и источник — public/media/README.md.
